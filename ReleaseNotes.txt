UpSparkle 1.1.1.0 - 2026-11-13

Added

- Automatic update settings: IsAutomaticCheckForUpdates, UpdateCheckInterval, and
  LastCheckTime on UpSparkleUpdater.
- CheckUpdateWithoutUI(): triggers a background update check without the progress UI.
- SetHttpHeader / ClearHttpHeaders: attach custom HTTP headers to appcast checks,
  release-note downloads, and update downloads.
- Error event, raised when the native updater reports a failure. The normal
  "no update found" outcome and user-cancelled installations are not reported.
- Eto Forms demo covering the Gtk, macOS, and WPF backends.
- Daily GitHub Actions workflow that checks Sparkle, libMacSparkle, and WinSparkle
  releases and opens a pull request when a newer version is available.
- NuGet package icon.

Changed

- Updated native dependencies: Sparkle 2.10.1, libMacSparkle 1.2.0, WinSparkle 0.9.4.
- Moved the demo projects from src/Demos/ to the top-level examples/ directory.
- Expanded the demo applications with automatic-check, interval, last-check,
  HTTP-header, and background-check controls.
- Expanded the test suite from 30 to 36 tests.
- Updated the README API reference to document the complete public surface.

Fixed

- The Error event no longer fires for "no update found" or user-cancelled
  installations.
- Native callbacks are safe under Mono AOT / IL2CPP via MonoPInvokeCallback.
